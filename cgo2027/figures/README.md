directory (`scripts/plot_all.sh`, or `make figures` in a benchmark).

- `genga_force_drift.pdf`, `genga_drift_timeseries.pdf` (Fig. 3, Fig. 4): `benchmarks/genga_nbody/genga_figures.py`
- `ozp_convergence.pdf` (Fig. 5), `ozp_surrogate.pdf`: `benchmarks/ozp/plot_ozp.py`, `plot_surrogate.py`
- `rchfsi_residuals.pdf` (Fig. 6): `benchmarks/chase_eigensolver/plot_chase.py`
